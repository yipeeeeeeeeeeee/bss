# Bee Swarm Guide

A multi-page Bee Swarm Simulator reference website project.

## Pages
- `index.html` — home page
- `bees.html` — bee stats table with expandable detail rows
- `fields.html` — field tabs and information cards
- `tools.html` — equipment page starter
- `crafting.html` — crafting calculator page starter

## Run locally
Open the folder in Visual Studio Code, then open `index.html` in a browser. The interactive pages load jQuery from the internet, so an internet connection is needed for those interactions.

## Images
Create an `images` folder and place the image files referenced by the HTML in it. Image files were not included in this starter archive. Make sure filenames match exactly.

## Notes
Some game information is placeholder text or starter values and should be verified before submission.
